# PitLane Diecast: курсов проект по „Големи данни“

Онлайн магазин за Hot Wheels и F1 умалени модели. Структурата е същата като на референтния проект (етап по етап, един файл за всеки етап).

## Стартиране

1. `pip install -r requirements.txt`
2. Етапи 1–6: `python main.py` (или всеки файл поотделно в IDE: `etap1.py` ... `etap6.py`). Графиките се показват с `plt.show()`; затворете прозореца, за да продължи.
3. Табло и изводи с LLM: `streamlit run dashboard.py`

Всичко се пуска **от папката на проекта**. VADER речникът се сваля еднократно (трябва интернет).

## LLM изводи (етап 8, по желание)

1. Копирайте `.env_example` като `.env`.
2. Вмъкнете ключ от https://aistudio.google.com/apikey в `GEMINI_API_KEY`.
3. В таблото натиснете „Генерирай изводи и препоръки“. Без ключ таблото работи, а таблицата „Изводи от изчисленията“ се показва винаги.

## Файлове

| Файл | Съдържание |
|---|---|
| `etap1.py` | Генериране на 5 свързани таблици (Faker, NumPy, Pandas), запис в `data/`, зареждане и проверка |
| `etap2.py` | Дубликати, типове, липсващи стойности, IQR / Z-score / boxplot, преди и след, Label и One-Hot Encoding, запис в `data/clean/` |
| `etap3.py` | Описателна статистика, нормално / равномерно / биномно разпределение, Pearson и Spearman, heatmap |
| `etap4.py` | Времеви ред, сезонност, 3 базови модела, LSTM, MAE / MSE / RMSE |
| `etap5.py` | Почистване на текст, честоти, биграми, TF-IDF, VADER, sentiment във времето |
| `etap6.py` | Клиентски характеристики, StandardScaler, Elbow, K-means (k = 4), бизнес анализ |
| `dashboard.py` | Етап 7 (табло с филтри) и етап 8 (LLM изводи с проверка) |
| `main.py` | Пуска етапи 1–6 |

## Данни

120 клиента, 24 продукта (Mainline, Premium, Treasure Hunt, F1 Collection, Track Sets, Accessories), 1200 поръчки (11.2025 – 10.2026), 350 мнения. Контролирани проблеми: липсващи възрасти, плащания, текстове и суми; дубликати; невалидни възрасти (150, −5) и оценки (0, 9); градове с различно изписване; дати във формат ДД.ММ.ГГГГ; нереални количества (50 бр.). Данните са симулирани: сезонност (Коледа, слаб януари и лято), 3 дни без сайт (10–12.02), различни предпочитания по тип клиент, по-ниски оценки през декември и за комплектите писти.
